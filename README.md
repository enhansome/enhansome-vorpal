## Extensions

*Extensions add to the functionality of Vorpal - programmatically or live.*

#### POSIX implementations

* [less](https://github.com/vorpaljs/vorpal-less) ⭐ 12 | 🐛 2 | 🌐 JavaScript | 📅 2016-02-04 - Implementation of the `less` command.
* [grep](https://github.com/vorpaljs/vorpal-grep) ⭐ 12 | 🐛 0 | 🌐 JavaScript | 📅 2016-04-11 - Implementation of the `grep` command.

#### Development tools

* [repl](https://github.com/vorpaljs/vorpal-repl) ⭐ 18 | 🐛 3 | 🌐 JavaScript | 📅 2022-02-03 - Drops your CLI into a REPL within your app's context.
* [tour](https://github.com/vorpaljs/vorpal-tour) ⭐ 18 | 🐛 0 | 🌐 JavaScript | 📅 2015-10-10 - Build an interactive tour for your Vorpal app.
* [log](https://github.com/AljoschaMeyer/vorpal-log) ⭐ 11 | 🐛 0 | 🌐 CoffeeScript | 📅 2016-01-08 - Advanced logging utility.
* [set-or-print](https://github.com/AljoschaMeyer/vorpal-setorprint) ⭐ 4 | 🐛 0 | 🌐 CoffeeScript | 📅 2015-11-02 - Easily set / get arguments with commands.
* [watch](https://github.com/vantagejs/vantage-watch) ⭐ 3 | 🐛 0 | 🌐 JavaScript | 📅 2015-08-03 - Updates your live Vorpal extensions in realtime.

#### Realtime

* [use](https://github.com/vorpaljs/vorpal-use) ⭐ 7 | 🐛 0 | 🌐 JavaScript | 📅 2015-08-24 - Import Vorpal extensions live: while your app is running.

#### Fun

* [hacker-news](https://github.com/vorpaljs/vorpal-hacker-news) ⭐ 6 | 🐛 0 | 🌐 JavaScript | 📅 2015-08-24 - Pulls the top trending items from Hacker News.

#### Toolbox

* [rc](https://github.com/subk/vorpal-rc) ⭐ 7 | 🐛 0 | 🌐 JavaScript | 📅 2016-04-21 - Simple .rc file support.
* [comment](https://github.com/subk/vorpal-comment) ⭐ 5 | 🐛 1 | 🌐 JavaScript | 📅 2016-04-22 - Bash-like comment support.
* [as-default](https://github.com/ialpert/vorpal-as-default) ⭐ 5 | 🐛 2 | 🌐 JavaScript | 📅 2019-10-21 - Triggers Vorpal task in case it runs without any specificly defined task.
